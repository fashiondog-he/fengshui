# 传统文化知识工具

本项目用于传统文化知识整理与古籍概念解释，不提供个人化现实结论或行动建议。当前四柱适配器仅返回固定测试样例，不会根据输入时间推算；输出会明确标为 Mock。

边界检查应在请求处理和检索之前调用。个人化输出应使用统一免责声明。调用方不得记录或保存原始出生资料等敏感输入。

## 运行测试

```powershell
python -m unittest discover -s tests -v
python scripts/scan_user_text.py
```

本阶段未接入真实计算规则、古籍检索或外部模型。所有请求应通过 `src/app.py` 的 `handle_request` 入口；个人化请求会被拒绝。原始请求只在内存中处理。
